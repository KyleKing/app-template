# test-template

Generated by copier-template-tester

A Deno web application built with Hono (routing), Vento (server-rendered templates), and htmx (interactivity), with shared TypeScript between server and browser and plain CSS without a framework.

## Setup

```sh
mise install
deno install
hk install
deno task test:e2e:install
mise run build
```

## Development

```sh
mise watch build # Keeps built files up to date
mise watch dev --restart |& tail-jsonl # Hot reloads on TS changes, while mise watches .vto. Optionally run with `pipx:tail-jsonl`

deno task test:watch

hk run pre-commit --all
```

## Production

```sh
deno task prod # Serves production app from built executable
```

## Layout

| Path             | Purpose                                                                        |
| ---------------- | ------------------------------------------------------------------------------ |
| `src/routes.ts`  | Page routes. Add new routers and pages here                                    |
| `src/api.ts`     | JSON endpoints under `/iapi`                                                   |
| `src/templates/` | Vento templates: `layouts/`, `pages/`, `partials/`                             |
| `shared/`        | Isomorphic modules transpiled to `public/shared/` for the browser              |
| `styles/`        | `tokens.css` and `base.css` load first, then `components/*.css` alphabetically |
| `scripts/`       | Build and server entry points                                                  |
